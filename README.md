PowerShell for Windows endpoints and IT operations, written to run on both Windows PowerShell 5.1 and PowerShell 7.

- [endpoint-compliance-scan](https://github.com/riffmillar-itadmin/endpoint-compliance-scan): a read-only scanner that checks a Windows machine against CMMC, NIST, DISA STIG, CIS, CSF, PCI DSS and HIPAA, with evidence for each requirement. Also on the PowerShell Gallery as `EndpointComplianceScan`.
- [jobsweep](https://github.com/riffmillar-itadmin/jobsweep): polls seven applicant-tracking platforms and the Microsoft careers API, and screens postings against your own title and location rules.
